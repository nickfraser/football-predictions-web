How it works

Rules

The rules

  • Every entrant — human or model — submits a complete predicted final table, positions 1 through 20, before the season begins. Submissions are locked before the squads are announced for the opening match: any prediction made after this time, gets the dreaded asterisk.
  • Predictions must be a strict ranking: every position from 1 to 20 used exactly once.
  • The published league table is computed from the recorded results using standard tie-breakers: points, then goal difference, then goals scored. Forecaster filters change what you see, never the table itself.

Scoring

After every played round, each entrant's predicted positions are compared with the current league table. Matchdays are cumulative: a round includes every fixture assigned to rounds 1 through N, including postponed matches played later.

Absolute difference (lower is better)

The absolute difference between predicted and actual position, summed across all 20 clubs. A perfect table scores 0; a fully reversed table scores 200.

Score (higher is better)

Scored profiles award each club points by how closely the prediction lands: an exact hit is worth 100 points, and the award falls away with every position of error — 80 for one place out, 68 for two, 58 for three … down to a single point at nineteen places out. The entrant's score is the sum across all 20 clubs.

Historical seasons also include random baselines — reproducible forecasts drawn by the engine as a reference rather than a published prediction, useful for context rather than as a model claim.

EPLBench

  • Models are real LLM runs, made through OpenCode against OpenRouter before the season, under the same lock as humans: one complete 1–20 table each, no updates. Each run is scored separately, even when the same model appears twice.
  • Reasoning: Unlike humans, LLMs are asked to explain the reasoning behind their predictions, which are also made available.
  • Comparison point: the latest contiguous complete round — the newest round N for which every round from 1 to N has all ten of its fixtures played. Model scores and absolute differences are measured at that round exactly like the humans' are.
  • Intelligence index: the Artificial Analysis intelligence score that OpenRouter reported for each model when the runs were selected, recorded at generation time and published unmodified — it is not calculated by this site.
  • Thinking level: each run records the reasoning effort the model supported (max down to none), as reported by OpenRouter.
  • Cost: the sum of each run's OpenRouter activity, computed offline after the run. Runs with no recorded activity are shown as unavailable — never zero.
